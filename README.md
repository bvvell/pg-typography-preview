# Подбор бесплатной замены FFF Acid Grotesk

Сайт для сравнения: https://bvvell.github.io/pg-typography-preview/

На сайте pg-branding.pl используется **FFF Acid Grotesk** (в CSS темы `pg_new` он подключён под именем `"Gilroy"`, файлы `FFF-AcidGrotesk-*.woff`). Здесь собраны бесплатные шрифты, которые ближе всего к нему по рисунку букв, и для каждого — статья
[«Jak typografia wpływa na markę?»](https://pg-branding.pl/blog/jak-typografia-wplywa-na-marke/) со стилями сайта, где заменён только шрифт.

## Как считалось сходство

1. Шрифты Acid Grotesk (Regular, Medium, Bold) взяты с сайта, кандидаты — 74 гротеска с Google Fonts плюс Switzer с Fontshare.
2. Каждая буква из набора `a–z A–Z 0–9 ąęłóśźż & ?` рендерится отдельно, масштабируется так, чтобы x-height совпадала с Acid, ставится на общую базовую линию и центрируется.
3. Растровые изображения буквы в Acid и в кандидате сравниваются по **IoU**: доля совпадающих пикселей от общей площади обоих. Учитываются форма, пропорции и насыщенность одновременно.
4. Для вариативных шрифтов перебирается вес с шагом 25 и подбирается свой вес под каждое начертание Acid: Regular, Medium и Bold.
5. **Сходство** — среднее IoU по Regular, Medium и Bold. **Ширина текста** — длина фразы относительно Acid при одинаковой x-height (1.00 = как у Acid).

Ограничение метода: IoU плохо видит мелкие характерные детали (хвостики, концевые элементы), поэтому лидеров дополнительно сверяли глазами.

## Как подключить выбранный шрифт

Заменить шрифт в теме — три правки. Пример для **Rubik**:

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Rubik:wght@300..900&display=swap">
```

```css
/* 1. семейство вместо "Gilroy" (Acid Grotesk) */
html { font-family: "Rubik", sans-serif; }

/* 2. x-height как у Acid Grotesk (0.55 от кегля) — буквы того же размера при том же font-size */
html { font-size-adjust: 0.55; }

/* 3. веса: Acid 400 → 425, 500 → 475, 700/bold → 575 */
html { font-weight: 425; }
b, strong { font-weight: 575; }
/* и в правилах темы: font-weight:400 → 425, font-weight:500 → 475, font-weight:bold → 575 */
```

Для других шрифтов — те же три шага, веса берутся из таблицы выше.
Старые `@font-face` для `"Gilroy"` при этом удаляются.

## Как устроены страницы

- `index.html` — список шрифтов с образцами текста. Сверху пять шрифтов, для которых есть главная (по сходству), дальше Rubik и остальные по сходству.
- `home/index.html` — список только этих пяти шрифтов со ссылками на главную и статью.
- `fonts/<шрифт>.html` — копия статьи. Это DOM страницы после выполнения JS (чтобы осталось оглавление), из которого вырезаны все скрипты, аналитика, cookie-баннер и кастомный курсор. CSS темы встроен в страницу, изменены только шрифт, веса и `font-size-adjust`; плюс системный курсор, который тема без JS скрывает.
- `home/<шрифт>.html` — копия главной pg-branding.pl, собранная так же, как статья, для пяти шрифтов: Familjen Grotesk, Funnel Sans, Switzer, Geist, Readex Pro. Отличия от оригинала:
  - убран блок `.showreel` с видео в первом экране;
  - шапка всегда в состоянии `.header.fixed`, то есть тёмный текст на белом фоне, а не белый поверх видео;
  - у `.main-page` добавлен отступ сверху 80px под шапку;
  - параллакс-картинка застыла в начальном положении.
- На всех страницах `noindex, nofollow`; `canonical` указывает на оригинальную страницу.

## Оговорки

- **Switzer** распространяется не через Google Fonts, а через Fontshare (Indian Type Foundry) по ITF Free Font License: бесплатно, в том числе для коммерческого использования. Можно ли самостоятельно хостить его файлы, перед продакшеном нужно проверить в тексте лицензии.
- `font-size-adjust` поддерживается в Chrome 127+, Safari 17+ и Firefox. В старых браузерах шрифт будет просто чуть мельче или крупнее.
- Мобильная вёрстка страниц отдельно не проверялась.
